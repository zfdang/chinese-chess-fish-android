两个版本，该选哪个？

推荐先安装 armv8-dotprod 版；如果无法正常运行，再换用 armv8 通用版。

推荐优先安装

armv8-dotprod 版

利用 ARM dotprod 指令优化引擎计算，需要设备支持该指令。

chessfish-armv8-dotprod.zip

如果该版本无法正常运行，请改用 armv8 通用版。

兼容回退

armv8 通用版

面向 ARM64 设备，无需额外的 dotprod 指令支持。

chessfish-armv8.zip

如果 dotprod 版无法正常运行，请下载此版本，解压后安装其中的 APK。

安装步骤

下载、解压、安装

  1. 打开发布页

    选择最新 release，展开 Assets，下载对应版本的 ZIP；本地目录也提供可用安装包。

  2. 取出 APK

    使用手机的文件管理器解压 ZIP，再打开 APK。如果下载的是 APK，可直接打开。

  3. 按系统提示安装

    通过浏览器或文件管理器安装时，Android 可能要求允许该应用安装未知来源应用。升级时请选择相同版本类型。

本地目录由网站维护，更新可能晚于 GitHub。请以 GitHub release 的发布说明和附件为准。

第一次使用？

从对弈开始，或者选一份棋谱逐步研习。
