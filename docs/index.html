为什么叫象棋鱼？因为它使用了开源的 Pikafish（皮卡鱼）象棋引擎。

01 / 对弈

与强手过招

选择执棋模式，回看历史着法。落子轨迹与可移动位置，让棋局更易读。

02 / 分析

看见更多好棋

请求引擎提示，查看候选着法与局势曲线。也可导入 FEN 局面，从任意位置继续对弈。

03 / 打谱

在经典中找答案

浏览内置 XQF 棋谱，逐步回放、阅读注释、探索分支，再以当前局面开始对弈。
